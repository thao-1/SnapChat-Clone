# SnapChat Clone

The app was deployed using Vercel: https://snap-chat-clone-iota.vercel.app/

A modern SnapChat-inspired web application built with Next.js, React, Tailwind CSS, and Radix UI.

## Features
- Chat, Stories, Lenses, Spotlight, and more
- Modern UI/UX with Tailwind CSS
- Component-driven architecture

---

## Getting Started

### 1. Clone the Repository
```
git clone https://github.com/thao-1/SnapChat-Clone.git
cd SnapChat-Clone
```

### 2. Install Dependencies
Using npm:
```
npm install --legacy-peer-deps
```
Or using yarn:
```
yarn install --legacy-peer-deps
```
Or using pnpm:
```
pnpm install --legacy-peer-deps
```

### 3. Run the Development Server
```
npm run dev
```
The app will be available at [http://localhost:3000](http://localhost:3000).

### 4. Build for Production
```
npm run build
npm start
```

## Project Structure
- `/app` - Next.js app directory (pages, routes)
- `/components` - Reusable React components
- `/public` - Static assets
- `/styles` - Global and component styles
- `/lib`, `/hooks`, `/types` - Utilities, hooks, and TypeScript types

---

## Requirements
- Node.js 18 or newer
- npm, yarn, or pnpm

---

## Troubleshooting
- If you encounter dependency issues, use `--legacy-peer-deps` with npm/yarn/pnpm.
- Ensure Node.js version is compatible.
